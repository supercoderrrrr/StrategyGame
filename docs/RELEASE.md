# Windows build / Windows 构建

[English](#english) · [简体中文](#简体中文)

## English

No public Windows download is available yet. Builds require the full private Unity project.

- Use Unity `2022.3.62f2`, targeting Windows x86_64. Include `MainMenuScene` followed by `Level1` in Build Settings.
- Package the entire build output, including the executable, data folder, and Unity runtime files.
- Before release, check menu navigation, a complete player/enemy turn, bomb-defusal win/loss conditions, and standalone startup on Windows without Unity installed. Confirm resource licenses before distributing the build.

## 简体中文

目前暂无公开的 Windows 试玩下载，构建需要完整私有 Unity 工程。

- 使用 Unity `2022.3.62f2`，目标平台为 Windows x86_64。Build Settings 中依次包含 `MainMenuScene` 和 `Level1`。
- 打包整个构建输出，包括 EXE、数据目录和 Unity 运行库。
- 发布前检查菜单操作、完整玩家/敌方回合、拆弹胜负条件，以及未安装 Unity 的 Windows 环境能否启动；分发前核对素材授权。
